# 🇧🇩 Bangladesh Disaster & Emergency Portal

## Project Overview

The Bangladesh Disaster & Emergency Portal is an educational web-based project designed to provide disaster awareness and emergency preparedness information for people in Bangladesh.

## Project Objectives

- Increase disaster awareness.
- Provide basic district-wise safety information.
- Share emergency contact information.
- Promote disaster preparedness.
- Provide cyclone shelter guidance.

## Main Features

1. Disaster Information
2. District-wise Information
3. Cyclone Shelter Guidance
4. Emergency Contact Numbers
5. Emergency Preparedness Checklist
6. Emergency Help Request Demo Form

## How to Run

1. Download the project repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Explore the website features.

## Important Notice

This is an educational demonstration project.

It does not provide verified live disaster alerts or send emergency requests to government authorities.

For real emergencies, contact official emergency services.
